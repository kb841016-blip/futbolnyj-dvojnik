# futbolnyj-dvojnik
Футбольный двойник: сайт для игроков и тренеров. Введи возраст, рост, вес, позицию и ногу, и получишь профи, похожего на тебя, и план тренировок на 4 недели под нужное качество: дриблинг, пас, удар, подкат, пенальти и другие. План подстраивается под возраст, есть лёгкие тренировки и подсказки, когда применять навык в матче
